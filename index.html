학생 직접 등록

전화번호가 로그인 아이디가 됩니다. 초기 비밀번호를 정해 학생에게 알려 주면, 학생이 처음 로그인할 때 자기 비밀번호로 바꿉니다. 이메일은 비밀번호를 잊었을 때 재설정 메일을 보내는 데 쓰입니다.

기존 학생이 전화번호로 로그인하려면 색인이 필요합니다. 관리자 화면을 열면 자동으로 맞춰지고, 아래 버튼으로 바로 다시 맞출 수도 있습니다.

인적사항 수정이 필요하면 관리자에게 문의해주세요. 이메일은 아래에서 직접 변경할 수 있습니다.

이메일 변경

이메일은 비밀번호 재설정 메일에 사용되므로, 변경하려면 현재 비밀번호를 입력해 본인 확인을 해야 합니다.

비밀번호 변경

로그인 아이디는 전화번호(또는 이메일)입니다. 비밀번호를 잊었다면 로그인 화면의 '비밀번호를 잊으셨나요?'를 이용하세요.
